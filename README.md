# Plantillas para análisis de tesis

Recursos abiertos y reproducibles para organizar datos y elegir métodos de análisis en proyectos de tesis. El material está pensado como punto de partida: adapta cada decisión a tus preguntas, diseño, disciplina y protocolo aprobado.

## Empieza aquí

1. Lee [Organización de datos](00-inicio/organizacion-datos.md).
2. Completa el [diccionario de datos](00-inicio/plantilla-diccionario-datos.xlsx) y la [lista de verificación](00-inicio/lista-verificacion-datos.md).
3. Usa [¿Qué plantilla necesito?](00-inicio/que-plantilla-necesito.md) para orientarte.
4. Para comparar dos grupos independientes en un resultado cuantitativo, consulta [Comparación de grupos](plantillas/01-comparacion-grupos/README.md).

## Principios

- Conserva una copia intacta de los datos originales y trabaja sobre una copia documentada.
- Define variables, unidades, códigos y datos faltantes antes del análisis.
- No elijas una prueba solo por un umbral de normalidad: considera diseño, estimando, gráficos y supuestos.
- Informa tamaños de efecto e intervalos de confianza, además de valores p cuando corresponda.
- Protege la confidencialidad y evita subir datos identificables a repositorios públicos.

## Estructura

- `00-inicio/`: organización, control y limpieza de datos.
- `plantillas/`: guías, ejemplos y datos demostrativos.
