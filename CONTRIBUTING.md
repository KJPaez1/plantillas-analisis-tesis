# Contribuir

Gracias por ayudar a que estas plantillas sean claras, reproducibles y útiles.

## Cambios bienvenidos

- Correcciones de redacción, accesibilidad y enlaces.
- Ejemplos sintéticos que no revelen información personal.
- Aclaraciones metodológicas respaldadas por referencias verificables.
- Mejoras de formato que mantengan compatibilidad con herramientas comunes.

## Antes de proponer un cambio

1. Describe qué problema resuelve y para quién.
2. Indica el diseño, población y alcance al que aplica cualquier recomendación estadística.
3. Incluye la referencia y fecha de consulta para afirmaciones metodológicas relevantes.
4. Verifica que enlaces, nombres de columnas y archivos coincidan.
5. Nunca incluyas datos reales identificables; utiliza datos sintéticos.

## Estilo

Escribe en español claro, define términos técnicos la primera vez y prefiere instrucciones accionables. Separa las decisiones obligatorias del diseño de las recomendaciones opcionales. No presentes una prueba como universalmente apropiada.
