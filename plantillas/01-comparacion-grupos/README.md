# Comparación de dos grupos

Material para planificar y reportar una comparación de un resultado cuantitativo entre dos grupos independientes. Los archivos de datos incluidos son sintéticos y solo ilustrativos.

## Recorrido

1. Revisa [flujo de trabajo](flujo-trabajo.md) y confirma que el diseño sea realmente independiente.
2. Lee la [explicación metodológica](explicacion.md) y define el estimando antes de elegir el método.
3. Explora `datos/datos.csv` junto con `datos/diccionario-datos.csv`.
4. Usa la [guía de reporte](guia-reporte.md) para comunicar métodos y resultados.
5. Consulta el [informe de ejemplo](ejemplo-completo/informe.html).

## Alcance y límites

La plantilla no cubre datos pareados, medidas repetidas, diseños por conglomerados, más de dos grupos ni modelos ajustados. La selección de método depende del diseño, la escala del resultado y los supuestos pertinentes. El ejemplo no constituye una recomendación para un estudio real.
