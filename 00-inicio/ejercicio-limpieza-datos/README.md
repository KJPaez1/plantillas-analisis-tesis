# Ejercicio de limpieza de datos

Este ejercicio breve usa una tabla deliberadamente pequeña. No es una base de investigación real.

## Datos de práctica

| id | grupo | edad | puntaje |
|---|---|---:|---:|
| P01 | control | 22 | 14 |
| P02 | Control | 21 | 12 |
| P02 | control | 21 | 12 |
| P03 | intervención | 250 | 18 |
| P04 | intervención | 23 |  |
| P05 | Intervencion | 24 | 17 |

## Actividades

1. Detecta el registro repetido y define cómo confirmar si realmente es duplicado.
2. Estandariza las etiquetas de `grupo` sin alterar el significado.
3. Investiga si `edad = 250` es error, valor especial o dato real; no lo cambies sin evidencia.
4. Registra el puntaje faltante y calcula cuántos faltan.
5. Anota cada decisión, la razón, fecha y responsable en un registro de cambios.

La limpieza no consiste en borrar automáticamente todo valor inusual. Consulta fuente y protocolo antes de corregir o excluir.
