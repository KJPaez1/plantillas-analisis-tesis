# Lista de verificación de datos

Marca cada punto y anota una acción si la respuesta es “no” o “pendiente”.

## Procedencia y resguardo

- [ ] El archivo original está preservado sin modificaciones.
- [ ] Se conoce la fuente, fecha de extracción, versión y permiso de uso.
- [ ] La copia de trabajo y los respaldos tienen acceso controlado.
- [ ] No hay identificadores personales innecesarios en la base analítica.

## Estructura y documentación

- [ ] La unidad de análisis y cada fila están definidas.
- [ ] Los nombres de columnas son únicos y consistentes.
- [ ] El diccionario define tipo, unidad, categorías y códigos de faltantes.
- [ ] Fechas, unidades y etiquetas siguen formatos consistentes.

## Calidad

- [ ] Se revisaron filas duplicadas según la clave del diseño.
- [ ] Se revisaron valores imposibles, rangos y errores de digitación.
- [ ] Se comprobaron categorías inesperadas y consistencia entre variables.
- [ ] Se cuantificaron y describieron los datos faltantes por variable/grupo.
- [ ] Los cambios de limpieza están documentados y son reproducibles.
- [ ] Se compararon conteos y resultados con la fuente o controles disponibles.

## Antes del análisis

- [ ] Los criterios de inclusión/exclusión se aplicaron según el protocolo.
- [ ] El plan analítico corresponde al diseño y a la pregunta de investigación.
- [ ] Se conservaron datos originales y una versión limpia identificable.
